  server.ts → app.ts → /api/v1 → routes/*.routes.ts → controller → service → Prisma / Redis / storage

  GET  /api/v1/           (welcome JSON)
  GET  /api/v1/health     (DB ping)
  GET  /api/v1/docs       (Swagger UI, if enabled)
